# Chronos

A complete video editor for Windows with Assist built in. It finds the beats, writes the captions, cuts the silence and lifts your subject out. Free, on your PC.

**[Download the latest version](https://github.com/firedsaif/chronos/releases/latest/download/Chronos-Setup.exe)**

Windows 10 or 11, 64-bit. About 149 MB.

## Installing

Chronos is not code-signed yet, so Windows may show "Windows protected your PC" the first time. Click **More info**, then **Run anyway**. The installer puts Chronos in your own user folder and does not need admin rights.

The first export downloads its renderer (about 270 MB), once. Some Assist tools download their model the first time you use them.
